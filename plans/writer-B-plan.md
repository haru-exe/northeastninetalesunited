### Ideas
1. **Displacement gradient → e_ij + ω_ij** (derived). Picture: two close points joined by a tiny arrow r; after deformation the arrow changes length/direction; over a tiny distance the displacement field is a flat (linear) function. Steps: (a) Taylor (2.1.1) u_i(P) = u_i^o + u_i,j r_j + higher order; (b) drop higher order since components of r are small; (c) r' = r + (u − u^o), so Δr = r' − r = u − u^o (2.1.2); (d) Δr_i = u_i,j r_j (2.1.3)–(2.1.4); (e) write the 3×3 matrix u_i,j (rows = component u,v,w; columns = derivative x,y,z) (2.1.5); (f) apply (1.2.10): u_i,j = e_ij + ω_ij (2.1.6), e_ij = ½(u_i,j + u_j,i), ω_ij = ½(u_i,j − u_j,i) (2.1.7); (g) with r_i = dx_i: u_i = u_i^o + e_ij dx_j + ω_ij dx_j (2.1.8); (h) rotation vector = dual vector ω_i = −½ε_ijk ω_jk, giving ω_1 = ω_32 = ½(∂u_3/∂x_2 − ∂u_2/∂x_3), ω_2 = ω_13 = ½(∂u_1/∂x_3 − ∂u_3/∂x_1), ω_3 = ω_21 = ½(∂u_2/∂x_1 − ∂u_1/∂x_2) (2.1.9), i.e. **ω** = ½∇×**u**. (Show ω_1 = ω_32 from the ε sum in two lines.)
2. **Geometric meaning, six relations** (derived, Fig 2.4: element ABCD with A = (x,y), B = (x+dx, y), C = (x, y+dy) goes to parallelogram A'B'C'D'). Picture: a rubber grid; stretch = change of length per original length; shear = change of a right angle. Steps for e_x: (a) u(x+dx,y) ≈ u + (∂u/∂x)dx and v(x+dx,y) ≈ v + (∂v/∂x)dx; (b) A'B' = [(dx + ∂u/∂x dx)² + (∂v/∂x dx)²]^½ = dx[1 + 2∂u/∂x + (∂u/∂x)² + (∂v/∂x)²]^½; (c) small-deformation step: gradients ~10⁻³, so squares ~10⁻⁶ are dropped and [1+2a]^½ ≈ 1+a (numbers: ∂u/∂x = 0.001, ∂v/∂x = 0.002 → exact A'B'/dx = 1.001002 vs 1.001; difference 2×10⁻⁶); (d) A'B' ≈ (1 + ∂u/∂x)dx; (e) e_x = (A'B' − AB)/AB = ∂u/∂x (2.2.1). Then e_y = ∂v/∂y (2.2.2) carried out in full on AC (no "similarly"). Shear: (f) γ_xy = π/2 − ∠C'A'B' = α + β; (g) α ≈ tan α = (∂v/∂x dx)/(dx + ∂u/∂x dx) ≈ ∂v/∂x, β ≈ ∂u/∂y; (h) γ_xy = ∂u/∂y + ∂v/∂x (2.2.3); sign: positive when the right angle between the positive axes decreases; radians. (i) tensor shear e_xy = ½γ_xy (matches (2.1.7)); (j) the six relations (2.2.4) [γ form], (2.2.5) [e form], (2.2.6) e_ij = ½(u_i,j + u_j,i), (2.2.7), strain matrix (2.2.8).
3. **Rigid-body motion** (derived + procedure). Picture: pick the element up and turn it. Fig 2.5: bottom edge turns by ∂v/∂x, left edge by −∂u/∂y; rigid rotation means both equal, e_xy = 0, ω_z = ½(∂v/∂x − ∂u/∂y) = (2.1.9)_3. Field u* = u_o − ω_z y, v* = v_o + ω_z x (2.2.9); verify e_x = e_y = e_xy = 0; 3D form (2.2.10): u* = u_o − ω_z y + ω_y z, v* = v_o − ω_x z + ω_z x, w* = w_o − ω_y x + ω_x y. Integration procedure: integrate normal strains (arbitrary functions of the other variables appear); put into shear-strain equations; separate variables; each separated piece is a constant; constants = rigid-body terms; displacements are fixed by strains only up to a rigid-body motion (book p.38).

### Ideas
1. **Transformation** (stated (2.3.1)–(2.3.3); derived (2.3.5)–(2.3.6)). Picture: a strain gauge reads stretch along its own direction only; turn the gauge, the reading changes though the deformation is the same. Steps: (a) strain is a second-order tensor so (1.5.1)_3 applies: e'_ij = Q_ip Q_jq e_pq (2.3.1); (b) rows of Q are the direction cosines (l,m,n) of x'_i (2.3.2); the six expanded equations (2.3.3) are stated (matrix product written out); (c) rotation by θ about z, CCW from x to x' (Fig 2.6): Q = [[cosθ, sinθ, 0],[−sinθ, cosθ, 0],[0,0,1]] (2.3.4); (d) multiply out Q e Q^T entry by entry to get (2.3.5): e'_x = e_x cos²θ + e_y sin²θ + 2e_xy sinθ cosθ, e'_y = e_x sin²θ + e_y cos²θ − 2e_xy sinθ cosθ, e'_xy = −e_x sinθ cosθ + e_y sinθ cosθ + e_xy(cos²θ − sin²θ); (e) identities cos² = (1+cos2θ)/2, sin² = (1−cos2θ)/2, 2 sinθ cosθ = sin2θ, cos²−sin² = cos2θ give (2.3.6): e'_x = (e_x+e_y)/2 + (e_x−e_y)/2 cos2θ + e_xy sin2θ, e'_y = (e_x+e_y)/2 − (e_x−e_y)/2 cos2θ − e_xy sin2θ, e'_xy = (e_y−e_x)/2 sin2θ + e_xy cos2θ; (f) check e'_x + e'_y = e_x + e_y. Polar components (Exercise 2.6): x', y' → r, θ with e_r = e'_x etc. Rosette: a gauge at angle θ measures e'_x(θ) only, three gauges give three equations for e_x, e_y, e_xy (Exercise 2.7). Sympy confirms (2.3.5), (2.3.6) as transcribed equal Q e Q^T.
2. **Principal strains** (derived). Picture: in three perpendicular directions a small cube only stretches, its right angles stay right. Steps: (a) e_ij symmetric so principal axes exist (Topic 2); (b) (e_ij − e δ_ij)n_j = 0, non-trivial n requires det = 0 → (2.4.1) −e³ + ϑ_1 e² − ϑ_2 e + ϑ_3 = 0; (c) invariants (2.4.2) ϑ_1 = e_1+e_2+e_3, ϑ_2 = e_1e_2 + e_2e_3 + e_3e_1, ϑ_3 = e_1e_2e_3, and in components ϑ_1 = e_kk, ϑ_2 = sum of principal 2×2 minors, ϑ_3 = det e; (d) diagonal form (2.4.3), no shear on principal axes; (e) directions: solve (e_ij − e^(k)δ_ij)n_j = 0 with n_i n_i = 1 (a non-zero row of the adjugate of e − e^(k) I gives n; verified); (f) dilatation (Exercise 2.11, derived in the explanation): box with edges a, b, c along principal axes → V_0 = abc, V = a(1+e_1) b(1+e_2) c(1+e_3), ΔV/V_0 = (1+e_1)(1+e_2)(1+e_3) − 1 = ϑ_1 + ϑ_2 + ϑ_3, products of strains dropped for small strains → ΔV/V_0 ≈ e_kk = ϑ (check: Exercise 2.10 numbers, exact 3.975×10⁻³ vs ϑ = 4×10⁻³).
3. **Spherical + deviatoric** (derived, short). Picture: uniform swelling (volume, shape kept) plus pure shape change (volume kept). Steps: ẽ_ij = ⅓e_kk δ_ij = ⅓ϑδ_ij (2.5.1), isotropic (same in all axes since δ_ij is); ê_ij = e_ij − ⅓e_kk δ_ij (2.5.2); e_ij = ẽ_ij + ê_ij (2.5.3); ê_kk = e_kk − ⅓e_kk·3 = 0; by (f) of idea 2 the deviatoric part changes no volume; same principal directions: ê_ij n_j = λn_i ⇔ e_ij n_j = (λ + ϑ/3)n_i, eigenvalues shift by ϑ/3.

### Ideas
1. **Why needed** (picture, no derivation). Six equations (2.2.5) for three unknown displacements; Fig 2.7 (four elements: continuous deformation fits, discontinuous one leaves gaps); continuous u gives nice strains but integrating arbitrary strains need not give single-valued displacements.
2. **Saint-Venant equations** (derived in index form). Steps: (a) differentiate (2.2.6) twice, e_ij,kl = ½(u_i,jkl + u_j,ikl); (b) swap pairs to write e_kl,ij = ½(u_k,lij + u_l,kij); (c) e_jl,ik = ½(u_j,lik + u_l,jik); (d) e_ik,jl = ½(u_i,kjl + u_k,ijl), each shown; (e) form e_ij,kl + e_kl,ij − e_ik,jl − e_jl,ik = ½(eight third-derivative terms); (f) continuous derivatives commute, so the terms cancel in pairs (u_i,jkl with −u_i,kjl, etc., four pairs shown) → 0 = (2.6.1); (g) counting: of the 81 index combinations 45 give 0 = 0 and the other 36 are repeats (up to sign) of six distinct equations (checked by sympy); (h) setting l = k (no sum) for (i,j,k) = (1,1,2), (2,2,3), (3,3,1) gives (2.6.2)_1–_3, e.g. e_11,22 + e_22,11 = 2e_12,12 is ∂²e_x/∂y² + ∂²e_y/∂x² = 2∂²e_xy/∂x∂y; (i,j,k) = (2,3,1), (3,1,2), (1,2,3) give (2.6.2)_4–_6, e.g. ∂²e_x/∂y∂z = ∂/∂x(−∂e_yz/∂x + ∂e_zx/∂y + ∂e_xy/∂z); (i) only three of the six are independent (stated: Exercises 2.15 Bianchi relations and 2.16 three fourth-order equations; not derived in the book here).
3. **Sufficiency and connectedness** (outline, stated as not examinable in full). Picture: reading u at P by adding up du along a path from P_o; it must not depend on the path. Key equations: (2.6.3) u_i^P = u_i^o + ∫_C u_i,j dx_j; (2.6.4) with e + ω; (2.6.5) by parts; (2.6.6) ω_ij,k = e_ik,j − e_jk,i; (2.6.7) u_i^P = u_i^o + ω_ij^P x_j^P + ∫_C U_ik dx_k, U_ik = e_ik − x_j(e_ik,j − e_jk,i); path independence ⇔ exact differential ⇔ (Stokes, simply connected) U_ik,l = U_il,k ⇔ (2.6.1). Simply connected = every closed curve shrinks to a point; a hole makes a region multiply connected, a cut from outer boundary to hole restores simple connection; Fig 2.9 (a)–(e): solid cylinder and cylinder with spherical cavity simply connected, cylinder with through hole multiply connected. Multiply connected: (2.6.2) necessary but not sufficient; further conditions called Cesàro integrals (named only).
